# Security

Please report vulnerabilities privately through GitHub: the **Security** tab of this repository →
**Report a vulnerability**. Do not open a public issue for them.

You will get an answer within a week.

Never send your Mail.ru password or app password, in a report or anywhere else. If you think a password
leaked (into a log, a screenshot, an issue), delete that app password on Mail.ru and create a new one.

Supported: the latest release only.
